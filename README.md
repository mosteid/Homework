# تطبيق متابعة الواجبات 3D للأندرويد (مع مشاركة الشاشة وقراءة رسائل واتساب)

مشروع أندرويد متكامل (Kotlin) يدمج نظام متابعة الواجبات الخاص بك مع **مشاركة الشاشة الأصلية في أندرويد (`MediaProjection`)** وقراءة رسائل واتساب العربية تلقائياً لتحديد الطلاب الذين أرسلوا الواجب والذين لم يرسلوا.

## كيف يعمل التطبيق على الموبايل؟
1. افتح التطبيق واختر الفصل المطلوب.
2. اضغط على **📡 الماسح الذكي لواتساب** ثم **🖥️ مشاركة الشاشة وبدء المسح**.
3. وافق على إذن مشاركة الشاشة (وإذن الظهور فوق التطبيقات الأخرى ليظهر شريط التحكم الصغير فوق واتساب).
4. افتح مجموعة واتساب الخاصة بالفصل ومرّر الرسائل؛ سيقرأ التطبيق الشاشة تلقائياً كل ثانيتين ويرصد أسماء الطلاب الذين أرسلوا الواجب مع عداد مباشر.
5. اضغط **⏹️ إنهاء** من الشريط العائم للعودة فوراً إلى **شاشة المراجعة والاعتماد**، حيث يظهر:
   - الطلاب الذين أدوا الواجب (بدون تكرار).
   - الطلاب الذين لم يظهروا في المسح (مع خيار تسجيلهم تلقائياً كـ «لم يؤدِّ الواجب ✗»).
   - اضغط **✅ اعتماد النتائج** لتحديث الجدول وتقرير الواتساب فوراً.

## طريقتان لاستخراج ملف التثبيت (`APK`)

### الطريقة الأولى: عبر Android Studio (على الكمبيوتر)
1. فك ضغط الملف `HomeworkTrackerAndroid.zip`.
2. افتح المجلد في **Android Studio** وانتظر اكتمال مزامنة Gradle.
3. من القائمة العلوية اختر: **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. انقل الملف الناتج `app/build/outputs/apk/debug/app-debug.apk` إلى موبايلك وثبّته.

### الطريقة الثانية: بدون Android Studio (عبر GitHub مجاناً)
1. ارفع ملفات هذا المجلد إلى مستودع جديد (Repository) على حسابك في GitHub.
2. افتح تبويب **Actions** وسيقوم ملف `.github/workflows/build-apk.yml` تلقائياً بدمج ملف اللغة العربية وبناء التطبيق.
3. بعد اكتمال البناء (حوالي 3 دقائق)، حمّل ملف **HomeworkTracker3D-Android-APK** وثبّته مباشرة على موبايلك الأندرويد.
